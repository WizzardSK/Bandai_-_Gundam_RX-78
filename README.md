# Bandai_-_Gundam_RX-78

Thumbnails for Bandai Gundam RX-78 software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails), named after the MAME short names, as the MAME `rx78_cart` software list has them.

Snaps from AntoPISA's [progetto-SNAPS MAME Software List Resources](https://www.progettosnaps.net/softwareresources/).
